# Matteo Di Iorio

Computer Engineering M.Sc. student at the University of Bologna.

I like building things around systems software: embedded firmware, telemetry pipelines, cloud-native infrastructure, and tools that help me understand how a system works end to end.

Some of my interests:

* Kubernetes, observability and telco/cloud-native infrastructure
* embedded software and real-time systems
* telemetry, dashboards and data pipelines
* Go, Rust, C/C++, Python and Linux-based tooling
* AI/ML systems, especially when they touch infrastructure or edge deployments

Current public project: [InspectRT](https://github.com/splicer3/inspectrt), a reproducible feature-memory anomaly-detection baseline for industrial visual inspection, focused on cross-platform runtime evidence and ONNX portability.

The majority of my embedded work comes from Formula Student hybrid vehicle electronics, but those repositories are obviously not public.
